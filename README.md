# 🍦 Ice Cream & Smoothies Website

A simple and attractive **Ice Cream & Smoothies e-commerce website** created using **HTML and CSS**. The project provides a clean frontend interface where users can explore different ice creams and smoothies along with their prices.

## ✨ Features

* 🏠 Home section with a visually appealing design
* 🍨 Ice cream and smoothie product listings
* 💰 Product names and prices
* 🔍 Search interface
* 🔐 Login interface
* ❤️ Wishlist interface
* 🛒 Shopping cart interface
* 📱 Clean and user-friendly layout
* 🎨 Custom styling using CSS

## 🛠️ Technologies Used

* **HTML5**
* **CSS3**

## 🚀 How to Run

1. Clone the repository.
2. Open the project folder.
3. Open `01project.html` in any modern web browser.
4. Explore the Ice Cream & Smoothies website.

## 🎯 Purpose

This project was created to practice **HTML structure, CSS styling, webpage layouts, navigation, and frontend UI design** while building a simple e-commerce-style website.
